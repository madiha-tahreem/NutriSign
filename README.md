# 🥬 NutriSign

Find possible nutrient deficiencies from your symptoms, and see what to eat to fix them.

🔗 **Live demo:** https://<your-username>.github.io/nutrisign/

## Features
- Search or tap symptoms, and add as many as you have
- Deficiencies ranked by how many of your symptoms match
- Nutrients needed and foods to eat for each deficiency
- Other symptoms listed so you can compare, with yours highlighted
- Browse all deficiencies, with a mobile-friendly layout and dark mode

## Tech
Plain HTML, CSS and JavaScript in a single `index.html`, with no build step or dependencies.

## Add more deficiencies
Edit the `DATA` array in `index.html` and copy an existing entry.

## Disclaimer
For general education only. This is not medical advice. See a doctor for diagnosis and before taking supplements.
